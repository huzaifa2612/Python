## 🚀 Getting Started

### 1. Requirements

- Python **3.10 or later** is recommended, particularly for examples using `match` / `case`.
- Git is needed only if you want to clone the repository using the command line.

Check your Python installation:

```bash
python --version
```

On Windows, you can also use:

```powershell
py --version
```

### 2. Clone the repository

```bash
git clone https://github.com/huzaifa2612/Python.git
cd Python
```

### 3. Run an example

For example, to run the introductory arithmetic script:

```bash
python "CH-2-Add-2-Numbers.py"
```

On Windows:

```powershell
py "CH-2-Add-2-Numbers.py"
```

### 4. Run file-handling exercises

Some file-handling scripts use sample files through relative paths. For those exercises, open a terminal in the relevant chapter folder before running the script. For example:

```bash
cd CH-9-File_Handling
python Ch-9_File-Handling.py
```

## 🎙️ Optional Voice Examples

The repository includes a couple of introductory voice-related scripts. These dependencies are **not required** for the other chapter exercises.

| Script | Additional package | Install command |
|---|---|---|
| `Pyttsx3.py` | `pyttsx3` | `python -m pip install pyttsx3` |
| `VoiceInput.py` | `SpeechRecognition` and a compatible microphone input setup | `python -m pip install SpeechRecognition` |

`VoiceInput.py` may also require **PyAudio**, depending on your operating system and Python setup. The example uses an online speech-recognition service, so an internet connection is required. Do not use it with private or sensitive audio.
