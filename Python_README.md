# Python Learning Repository

A personal collection of Python examples and practice exercises created while learning Python through chapter-based lessons. The repository focuses on programming fundamentals, problem-solving, and core Python concepts.

## Topics Covered

- **Python fundamentals:** variables, input/output, data types, operators, and simple programs
- **Strings and collections:** string operations and slicing, lists, tuples, dictionaries, and sets
- **Control flow:** conditional statements and loops
- **Functions:** reusable functions and recursion
- **File handling:** reading, writing, appending, and working with text files
- **Object-oriented programming:** classes, objects, attributes, constructors, and `self`
- **Inheritance and advanced OOP:** inheritance, `super()`, class methods, properties, and operator overloading
- **Advanced Python:** exception handling, the walrus operator, `match`/`case`, dictionary operations, enumerations, list comprehensions, and modules
- **Functional programming:** lambda expressions, `map()`, `filter()`, and `reduce()`
- **Additional practice:** searching algorithms, polymorphism, and introductory voice-related examples

## Getting Started

### Requirements

- Python **3.10 or later** is recommended.
- Most examples use Python's standard library.
- Some scripts request input in the terminal.
- A few optional voice examples require additional packages (see **Optional Voice Examples** below).

### Run an example

Clone the repository:

```bash
git clone https://github.com/huzaifa2612/Python.git
cd Python
```

Run a script from the repository root:

```bash
python "CH-2-Add-2-Numbers.py"
```

On Windows, you can also use the Python launcher:

```powershell
py "CH-2-Add-2-Numbers.py"
```

For file-handling exercises that read or write nearby sample files, change into that chapter's directory before running the script. For example:

```bash
cd CH-9-File_Handling
python Ch-9_File-Handling.py
```



## Optional Voice Examples

Two standalone scripts demonstrate basic text-to-speech and speech recognition:

- `Pyttsx3.py` uses the `pyttsx3` package. Install it with:

  ```bash
  python -m pip install pyttsx3
  ```

- `VoiceInput.py` uses `SpeechRecognition` and microphone input. It may require `PyAudio` and a working microphone:

  ```bash
  python -m pip install SpeechRecognition PyAudio
  ```

  This example calls `recognize_google()`, which uses an external speech-recognition service and requires an internet connection. Avoid using it with sensitive audio.

These packages are only needed for the corresponding optional scripts; they are not required for the chapter exercises in general.

## How to Use This Repository

1. Open a chapter folder.
2. Choose a Python file related to the concept you are practising.
3. Read the comments and code.
4. Run the script from a terminal.
5. Experiment by changing inputs or modifying the example.

The files are mostly independent learning examples rather than one combined application. Some exercises are intentionally small or exploratory.
